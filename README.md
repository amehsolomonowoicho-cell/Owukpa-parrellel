# Owukpa (Idoma) - English Parallel Dataset 🇳🇬

**First ever digital parallel corpus for Owukpa, a Southern Idoma dialect [ISO 639-3: idu] spoken by ~200,000 people in Benue State, Nigeria.**

### Why This Matters
Idoma languages have many dialects but near-zero digital resources. Owukpa is especially under-documented, with no existing NLP dataset, keyboard, or translation tools. This repo begins digital preservation before the dialect loses ground.

### Dialect Note
**This dataset documents Owukpa specifically.** While it shares ~80% mutual intelligibility with Central Idoma (Otukpo), Owukpa has distinct tone patterns, vocabulary, and expressions. This specificity makes the data valuable for dialect-aware NLP, linguistics research, and cultural preservation.

### What's Inside
- `owu-en.txt`: 20+ parallel Owukpa-English sentences, growing daily
- **Tone marked:** Uses á, é, í, ó, ú, à, è, ì, ò, ù to preserve linguistic accuracy
- **License:** CC0-1.0 = 100% free for research, education, and commercial use  
- **Quality:** Created and validated by native Owukpa speaker, Ameh Solomon Owoicho
